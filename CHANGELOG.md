#### [v0.4.0](https://github.com/gsharp-aai/n8n-nodes-assemblyai/compare/v0.3.1...v0.4.0)

> 22 June 2026

##### Added

- **Universal-3.5 Pro** — added to the recommended `speech_models` (priority array) example. Like Universal-3 Pro, it is only selectable via `speech_models` (the API rejects pro models on the singular `speech_model` param)
- **Temperature** field on `transcript:create` — sampling temperature 0.0–1.0. Only valid with Universal-3 Pro or Universal-3.5 Pro speech models
- **Redact Static Entities** field — custom redaction labels mapped to lists of exact-match terms (`{ "LABEL": ["term1", "term2"] }`). Requires `redact_pii: true`. Server uses these for literal find-and-replace in transcripts and (if `redact_pii_audio: true`) in the redacted audio
- **Code Switching** boolean re-added to `language_detection_options` (was removed in v0.3.0 when the API silently stripped it; now publicly documented and honored on accounts with the feature enabled)
- **EU data residency** — `Data Region` selector added to the AssemblyAI credential. Selecting `EU` routes every request to `api.eu.assemblyai.com` / `llm-gateway.eu.assemblyai.com`, keeping audio and transcription data within the European Union

##### Changed

- **`auto_chapters`** is now labeled `Auto Chapters (Deprecated)` with guidance to use the LLM Gateway resource instead, matching the AssemblyAI public docs
- **`speech_models` (priority array) is now the only way to select a model.** It lists `universal-3-5-pro,universal-3-pro,universal-2` as the recommended priority order. Leave it empty to let the API choose.
- User-Agent on every request is now `n8n-assemblyai-node/0.4.0`

##### Removed

- **Legacy singular `Speech Model` field removed.** The async API treats every modern model (`universal-2`, `universal-3-pro`, `universal-3-5-pro`, `qwen3-asr`) as `speech_models`-only and rejects them on the singular `speech_model` param with a 400 — so the field could only ever submit legacy `universal`. Use the `speech_models` priority array instead (e.g. `universal-3-pro,universal-2`).
- **`slam-1`**, **`nano`**, and **`best`** are no longer AssemblyAI models — removed everywhere. Workflows that pinned these strings will receive the API's "model not supported" error; migrate to `universal-3-pro` or `universal-3-5-pro`.

##### ⚠️ Breaking changes

- **Saved workflows that set the singular `Speech Model` field lose that selection.** The field no longer exists in the node; on next save the value is dropped. Re-select your model in **Speech Models (Priority Order)** (comma-separated, e.g. `universal-3-pro,universal-2`). Behaviour is otherwise unchanged — the API was already rejecting modern models on the singular param.

#### [v0.3.0](https://github.com/gsharp-aai/n8n-nodes-assemblyai/compare/v0.2.0...v0.3.0)

> 12 May 2026

- v0.3.0 — sync with current async transcription API; remove LeMUR [`#4`](https://github.com/gsharp-aai/n8n-nodes-assemblyai/pull/4)
- feat: v0.3.0 — sync with current AssemblyAI async transcription API [`1e927af`](https://github.com/gsharp-aai/n8n-nodes-assemblyai/commit/1e927af2ffe0db710a4602347976188937496e28)

- feat(llm_gateway): add documented Chat Completion fields [`4787d8f`](https://github.com/gsharp-aai/n8n-nodes-assemblyai/commit/4787d8f5f897c41fcba89d9bc97cae936e7efa2e)

##### Added

- **`speech_models` array** — priority list, e.g. `"universal-3-pro,universal-2"` (the legacy single `speech_model` field is kept for backwards compatibility)
- **Universal-3 Pro prompting** — `prompt` field (up to 1500 words) to steer transcription style
- **Medical Mode** — `domain: "medical-v1"` for medical-terminology accuracy
- **Remove Audio Tags** — `remove_audio_tags: "all"` strips inline annotations (Universal-3 Pro)
- **Top-level `speakers_expected`** field; `speaker_options` exposes `min_speakers_expected` / `max_speakers_expected`
- **PII redaction**: `redact_pii_return_unredacted` returns both versions; `override_audio_redaction_method: "silence"` for redacted audio
- **Language detection options**: `expected_languages`, `fallback_language`, `code_switching_confidence_threshold`
- **Transcript list**: `throttled_only` query parameter
- **LLM Gateway → Chat Completion**:
  - `transcript_id` to inject a transcript into the prompt via the `{{ transcript }}` tag
  - `Tool Choice: Specific Function` + Tool Choice Function Name to force a specific tool call
  - `Tool` message role with `tool_call_id` for multi-turn tool-call round-trips
  - JSON Repair post-processing toggle (`post_processing_steps: [{ type: "json-repair" }]`)

##### Changed

- Marked `summarization`, `summary_model`, `summary_type` as **Deprecated** — use the LLM Gateway resource instead
- `redact_pii_policies` aligned to the 43 documented entries

##### Removed

- **LeMUR resource and all its operations** (Summary, Question & Answer, Custom Task, Get Response, Purge Data). LLM Gateway is the supported successor.
- Duplicate PII policy entries `us_driver_license` and `us_healthcare_number` (canonical `drivers_license` and `healthcare_number` remain)
- `code_switching` boolean from `language_detection_options` (use top-level `language_codes` for code-switching transcription)

##### ⚠️ Breaking changes

- **LeMUR resource removed.** Workflows using LeMUR will fail to load. Migrate to the LLM Gateway resource (Chat Completion for prompting, Speech Understanding for translation/speaker_id/custom_formatting).
- **Duplicate PII policies removed.** Workflows referencing `us_driver_license` or `us_healthcare_number` should switch to `drivers_license` / `healthcare_number`.
- **`code_switching` toggle removed** from Language Detection Options. Behavior is unchanged, but saved workflows referencing the toggle will silently drop it on next save.
- **Legacy `speech_model` field** is rejected by the API for accounts created after the deprecation date. Migrate to the `speech_models` priority array (e.g., `"universal-3-pro,universal-2"` in the UI).
